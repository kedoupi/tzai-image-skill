# Rubric: pattern-compile

Compare `before` (naive one-liner + kind defaults) vs `after` (slot-compiled prompt ± matrix flags).

## Scores (1–5)

| Dimension | Question |
| --- | --- |
| Composition | Hierarchy, focal subject, whitespace |
| Spec match | Did required slots appear (steps, labels, layers, open lid, …)? |
| Text / labels | Readable, exact when locked, no garble |
| Clutter | Module cap respected; no invented dense chrome |
| Rights / safety | No deceptive claims; synthetic data only when UI |

## Decision rule

Prefer **spec match** over pure aesthetics. Kind prefixes alone can look premium; compile wins when content must be exact.

## Report location

Write notes to `artifacts/live/pattern-compile/<version>/report.md`.
