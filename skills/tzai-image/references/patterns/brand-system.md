# Brand System

## `brand-identity`
Extract a single brand idea, audience tension, and differentiation. Explore mark, palette, material, and tone through `logo`, `icon`, and `moodboard`, then select one direction for refinement. Run trademark and accessibility review separately.

## `brand-touchpoint`
Start with approved logos, colors, type, and voice. Map each asset to its touchpoint role, with shared spacing and image treatment. Generate direction boards only; place production marks and copy with approved source files.
